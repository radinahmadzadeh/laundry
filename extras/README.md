# extras

Files that belong to the project but are not used by the site. Nothing in here is
served or loaded; it is kept so nothing is lost.

```
images/                  original, full-size photos (the site uses smaller copies)
  hero/                  earlier hero background and a studio photo
  home-gallery/          full-size gallery photos (the site shows the *-sm.jpg copies)
  pricing-categories/    earlier pricing-category pictures (the site uses men/women/home.jpg)
tools/                   local helper scripts (git-ignored)
```

To use one of these images on the site again, copy it back under `frontend/static/`.
